# ESPHome RV Level

</div>

**ESPHome RV Level** is a reusable ESPHome package and standalone Progressive Web App (PWA) for leveling campervans and RVs. It pairs an **LSM6DSOX** 6-axis IMU over I2C with a real-time 3D WebGL visualization served directly from the ESP32's flash storage.

---

## 🌟 Key Features

- **3D WebGL Leveling PWA**:
  - Real-time pitch and roll visualization with 5× tilt magnification, dynamic ground plane, and automatic top-down/orbit camera views.
  - Calculates per-corner lift height (in inches) to help you place leveling blocks under the low wheels.
  - Served directly from ESP32 flash via [`esphome-web-host`](https://github.com/gongloo/esphome-web-host) with offline service worker caching and Home Screen installation.
  - Includes a built-in **Demo Mode** (`?demo=1`) for previewing the interface without hardware.
- **LSM6DSOX IMU & Motion Detection**:
  - Uses ESPHome's native `lsm6ds` and `motion` components with configurable axis mapping (`imu_axis_x`, `imu_axis_y`, `imu_axis_z`).
  - Publishes smoothed `Van Pitch` and `Van Roll` sensors, `IMU Temperature`, and a `Van Moving` binary sensor.
- **NVS-Persisted Calibration**:
  - Set your current parked stance as level (`Calibrate Van Level`) or revert to factory defaults (`Reset Van Level Calibration`) directly from the PWA or Home Assistant.

## 🔌 Hardware & Wiring

Any ESP32 board (e.g., LOLIN C3 Mini, ESP32 DevKit, or ESP32-S3) connected via I2C to an **LSM6DSOX** (or compatible LSM6DS) breakout such as the Adafruit LSM6DSOX. The standalone [`example.yaml`](example.yaml) targets a **LOLIN C3 Mini** (`lolin_c3_mini`, with `output_power: 8.5dB` for reliable Wi-Fi):

| Signal | Default LOLIN C3 Mini Pin (`example.yaml`) | Notes |
| :--- | :--- | :--- |
| **VIN / 3V3** | 3.3V | Power supply |
| **GND** | GND | Common ground |
| **SDA** | `GPIO8` | I2C data (customize in your device YAML) |
| **SCL** | `GPIO10` | I2C clock (customize in your device YAML) |

Default I2C address is `0x6A` (configurable via `imu_address`).

### Axis Mapping

Because IMUs can be mounted in any orientation, `rv-level.yaml` exposes `imu_axis_x`, `imu_axis_y`, and `imu_axis_z` substitutions. Configure them so that:

- **+X** points toward the **rear** of the vehicle (+pitch = front high)
- **+Y** points toward the **passenger** side
- **+Z** points **up**

## 🛠️ ESPHome Configuration & Setup

### 1. File Structure

```text
├── rv-level.yaml                          # Bare-bones reusable ESPHome package
├── example.yaml                           # Standalone ESP32 example configuration
├── LICENSE                                # MIT License
├── README.md                              # This documentation
└── data/
    └── htdocs/                            # Static PWA assets (manifest & SW auto-generated by pwa_host)
        ├── level.html                     # 3D WebGL leveling interface
        ├── apple-touch-icon.png           # App icon
        ├── favicon.svg                    # Vector favicon
        └── ProMaster_2015_White_meshopt.glb # Compressed 3D van model
```

### 2. Option A: Include as a Package (Recommended)

Include `rv-level.yaml` in your existing ESPHome device configuration (alongside your own `i2c:` and `web_server:` configuration):

```yaml
packages:
  rv_level:
    url: https://github.com/gongloo/esphome-rv-level
    ref: main
    files: [rv-level.yaml]
    # Or, for a local checkout:
    # rv_level: !include ../esphome-rv-level/rv-level.yaml

substitutions:
  # Optional overrides (shown with defaults)
  imu_address: "0x6A"
  imu_axis_x: "-x"
  imu_axis_y: "z"
  imu_axis_z: "y"

i2c:
  sda: GPIO21
  scl: GPIO22

web_server:
  port: 80
  version: 3
```

> [!NOTE]
> `rv-level.yaml` automatically loads [`esphome-web-host`](https://github.com/gongloo/esphome-web-host) and [`meshoptimizer`](https://github.com/zeux/meshoptimizer) for the PWA. Make sure your device config defines `i2c:` and `web_server:` (version 3).

### 3. Option B: Standalone Deployment (LOLIN C3 Mini)

Use [`example.yaml`](example.yaml) as a starting point for a dedicated LOLIN C3 Mini leveling node. Clone this repository (or reference it via GitHub), add your Wi-Fi, API, and OTA credentials, and flash:

```yaml
packages:
  rv_level_standalone:
    url: https://github.com/gongloo/esphome-rv-level
    ref: main
    files: [example.yaml]
    # Or, from inside a local clone:
    # rv_level_standalone: !include example.yaml

wifi:
  ssid: !secret wifi_ssid
  password: !secret wifi_password

api:
  encryption:
    key: !secret api_encryption_key

ota:
  - platform: esphome
    password: !secret ota_password
```

Alternatively, grab a pre-built binary from [GitHub Releases](../../releases).

> [!NOTE]
> When validating `example.yaml`, ESPHome emits an informational warning that `GPIO8` is a strapping pin on ESP32-C3; this is expected for the LOLIN C3 Mini's hardware I2C SDA pin.

Then validate and flash with:

```bash
esphome config your-device.yaml
esphome run your-device.yaml
```

### 4. Substitutions Reference

| Substitution | Default | Description |
| :--- | :--- | :--- |
| `imu_address` | `"0x6A"` | I2C address of the LSM6DS sensor |
| `imu_update_interval` | `"100ms"` | IMU polling interval |
| `imu_axis_x` | `"-x"` | Vehicle rear axis mapping |
| `imu_axis_y` | `"z"` | Vehicle passenger-side axis mapping |
| `imu_axis_z` | `"y"` | Vehicle up axis mapping |
| `motion_threshold` | `"0.05"` | Acceleration threshold for `Van Moving` |
| `motion_duration` | `"5s"` | Hold duration before `Van Moving` clears |
| `default_wheelbase_in` | `"159.0"` | Initial wheelbase in inches (adjustable at runtime) |
| `default_track_width_in` | `"71.0"` | Initial track width in inches (adjustable at runtime) |
| `web_host_component_source` | `"github://gongloo/esphome-web-host@v3.0.1"` | External component source for `web_host` and `pwa_host` |

## 📲 Web Interface & PWA

Once flashed, open `http://<device-name>.local/level` (or `http://<device-ip>/level`) in your browser:

- **Install as App**: On iOS Safari or Android Chrome, use **Add to Home Screen** / **Install App** for a full-screen standalone experience.
- **Calibration**: Tap the spirit-level icon in the top-right corner to set your current parked stance as `0.0°` or reset calibration to factory defaults.
- **Vehicle Dimensions**: Adjust **Wheelbase** and **Track Width** (in inches) at runtime from the stock ESPHome web UI (`http://<device-name>.local/`) or Home Assistant; values persist to NVS and update per-corner lift calculations live.
- **Demo Mode**: Append `?demo=1` (e.g., `/level?demo=1`) to test pitch/roll sliders and presets without live IMU data.
